# Translations

The header, footer, home page, daily check-in, symptom checker, Find doctors, Learn list, and Login are translatable. The Learn guides, privacy policy, terms, and signed-in pages are still English only. English, French, and Spanish exist (French and Spanish are drafts).

## Add a language
1. Copy `src/i18n/en.js` to a new file, such as `src/i18n/yo.js`.
2. Change `meta.name` to the language's own name, set `reviewed: false`, and translate every string value (leave the keys and any `{n}` or `{goal}` markers as they are).
3. In `src/i18n/index.jsx`, import the file and add it to the `languages` object.
4. Have a fluent speaker AND a medical professional check it. Only then set `reviewed: true`.
   Until then the app shows a "draft, not checked by a medical professional" notice and marks the language "(draft)".
For right-to-left languages set `dir: "rtl"` (the layout styles will need extra work).

## Translate another page
Replace each piece of text with `t("some.key")` (from `const { t } = useT();`), and add that key to every language file.
A missing translation falls back to English, so nothing ever shows blank.
